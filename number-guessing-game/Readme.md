# Number Guessing Game

Command-line number guessing game in Java. The computer picks a number between 1 and 100, you get 5 attempts, and it tells you if each guess is too high or too low.

Built to practice loops, conditionals and `Scanner` input.

## Run it

```
javac NumberGuessingGame.java
java NumberGuessingGame
```

Needs the JDK installed.
